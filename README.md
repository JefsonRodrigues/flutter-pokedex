# 📱 Flutter Pokédex

A Pokédex app built with Flutter using:

* Flutter
* Riverpod
* Dio
* SharedPreferences
* PokeAPI

## ✨ Features

* Infinite scroll
* Favorite Pokémons
* Local persistence
* Pokémon details
* Search system
* Responsive UI

## 🚀 Technologies

* Flutter
* Riverpod
* Dio
* SharedPreferences




## 📦 Installation

```bash
git clone URL_DO_REPOSITORIO
flutter pub get
flutter run
```
